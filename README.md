**MVP: анализ банковских отзывов с помощью ИИ**

Готовые нейросети определяют тональность отзывов: негатив, нейтрально или позитив. Дополнительно считаются ML-метрики и показатели для оценки возможной экономии времени сотрудников.

**Что сделано**

7 540 отзывов из Kaggle — полное сравнение трёх RuBERT.
1 000 отзывов — сравнение XLM-R на русском и после перевода.
12 392 отзыва разных банков — загружен и изучен новый набор; на 3 420 отзывах сохранены ответы XLM-R. Результаты этой обработанной части: Macro-F1 = 0,3559, Accuracy = 31,96%.
Для бизнеса рассчитаны доля ручной проверки и охват негативных оценок; FTE и ROI показаны как сценарий с допущениями, а не подтверждённая экономия.
Для повторения исходного сравнения запускайте ноутбук с самого начала: первый датасет — Kaggle, sber_app.csv.

**Как понимать результат**

Macro-F1 — основная метрика для трёх классов; Accuracy — доля совпадений со звёздами.
Precision, Recall, матрица ошибок показывают ошибки каждого класса.
Manual review share — доля сообщений, направляемых сотруднику; negative coverage — сколько негативных оценок попало на проверку.
FTE/ROI рассчитаны с заданными предположениями о времени и стоимости труда.
При полном расчёте появляются mvp_results/predictions.csv, metrics.csv, FINAL_STATUS.json. При прерванном запуске, после выполнения ячеек восстановления, используются predictions_partial.csv, metrics_partial.csv, business_metrics_scenario_partial.csv, FINAL_STATUS_partial.json.

Ограничения: оценки 1–2 звезды считаются негативом, 3 — условно нейтрально, 4–5 — позитивом. Звёзды могут не совпадать со смыслом текста.
